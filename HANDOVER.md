# Handover

## Delivered

Consolidated React/FastAPI project, lockfile, Alembic migrations, PostgreSQL/SQLite configuration, local bootstrap/launchers, container recipes, private-secret generation, offline queue/readiness, member-aware return accounting, scoped advisories, demo scenarios, printable passes/posters, tests and operational guides. Existing useful modules have been retained.

Read README.md for exact startup. The default demo uses SQLite and generated private accounts. No `.env`, database, dependencies, private logs, backups or staff credentials are included in the ZIP. Sample QR files are local-only fixtures; regenerate them with your installation secret. Old input-repository validation reports are historical, not current evidence.

## Acceptance

See TEST_REPORT.md for executed commands and results. A production build and unit/API tests are not substitutes for camera, offline-browser, PostgreSQL or mountain-field verification. This delivery is not labelled fully working against every acceptance gate.

## User-owned steps

1. Install supported Python/Node, extract and run the README commands. Read generated staff credentials locally from `.env`.
2. Test the three-role demo using the guide. For physical phones provide trusted HTTPS and a reachable host. Do not test real emergency calls/messages.
3. Run PostgreSQL migrations and restart tests with Docker, then a backup/restore drill against a new disposable database.
4. Supply a domain, hosting account, monitored contact information and private production credentials only when ready to deploy; no public deployment occurred here.
5. Obtain licensed and reviewed route geometry, checkpoint/facility verification, local rescue/medical review, language/accessibility review and legal/privacy approval.
6. Close the software gaps listed in IMPLEMENTATION_STATUS.md before a real participant pilot. Use invented data until then.

## Known limits

Offline records are device-local until uploaded. Server receipt is not staff acknowledgment or dispatch. Family sharing is last-report information, not live GPS. Forecast issue time is unknown; cached data may be stale. No reviewed real-route navigation is supplied. Legacy checkpoint status updates do not yet enforce expiry, and there is no dedicated device-heartbeat fleet view or full historical note-edit audit. Native Windows, live external weather, real camera/GPS and current browser quality gates remain unverified as described in the test report.
